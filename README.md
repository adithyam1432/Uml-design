# Classroomly - Smart Classroom Management

Classroomly is a modern, clean, and responsive dashboard for managing schools, classes, students, and attendance. Designed with a minimal aesthetic inspired by tools like Linear and Notion.

**Live Preview:** `index.html` - Open in any browser.

### Preview
- Workspace: Riverside School (Admin)
- Design System: Space Grotesk + DM Sans
- Colors: Coral, Yellow, Blue, Purple pastel stats

---

### ✨ Features

**Workspace Management**
- Sidebar navigation with active states
- Workspace switcher (Riverside School)
- Upgrade to Pro card
- User profile: Alex Morgan (Administrator)

**Dashboard Overview**
- `Good morning` personalized header
- 4 Stat Cards:
    - Active Students: 1,248 (+12.5%)
    - Classes Today: 24 (+8.2%)
    - Average Attendance: 94.8% (+2.4%)
    - Tasks to Review: 18 (6 due today)
- Mini bar charts in each stat card

**Attendance Overview**
- Weekly attendance bar chart (Mon-Fri)
- Average 94.8% with trend

**Today's Schedule**
- Timeline view with Live indicator
- 4 Classes: Math, History, Biology Lab, English

**Lower Panels**
- Recent Activity feed
- Class Performance by subject with progress bars

**Interactions**
- Add new class modal
- Search anything
- Notifications toast
- View switching via data-view
